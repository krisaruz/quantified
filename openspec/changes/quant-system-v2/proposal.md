## Why

当前系统是一个功能原型，具备基础的数据获取、过滤、评分、回测和推荐能力。但要成为一个工程级的量化交易系统，存在以下核心短板：

1. **策略单一**：仅支持 "double_low" 一种策略，无法扩展、对比、组合多种策略
2. **风控简陋**：只有止损和回撤暂停两个规则，缺乏仓位管理、相关性控制、行业集中度限制
3. **分析薄弱**：绩效报告仅有基础指标，缺乏归因分析、基准对比、因子暴露分析
4. **数据管道脆弱**：无数据质量校验、无增量同步状态机、无多数据源容错
5. **执行模型粗糙**：固定滑点、无订单管理、无成交模拟细化
6. **单组合限制**：只支持一个持仓组合，无法对比不同策略的实际表现
7. **无可观测性**：无实时监控、无告警、无策略健康度评估

本 change 将系统从"可工作的原型"升级为"工程级量化平台"，覆盖策略框架、风控引擎、分析仪表盘、数据管道增强、执行引擎、多组合管理、监控告警、API 网关八大模块。

## What Changes

### 1. 策略框架 (Strategy Framework)
- 策略注册表 + 插件架构：支持动态加载多种策略
- 因子库：动量、价值、质量、技术指标等标准化因子
- 策略组合器：多策略信号加权融合
- 策略版本管理：参数快照 + 历史回测对比

### 2. 风控引擎 (Risk Engine)
- 仓位管理算法：等权、风险平价、凯利公式
- 相关性矩阵：控制组合内标的的相关性
- 行业/板块暴露限制
- VaR/CVaR 计算
- 压力测试框架
- 回撤恢复规则（阶梯式恢复）

### 3. 分析仪表盘 (Analytics Dashboard)
- Brinson 归因分析（资产配置 + 选股贡献）
- 基准对比（中证转债指数、沪深300）
- 风险调整指标扩展（Sortino、Calmar、信息比率）
- 因子暴露可视化
- 月度/季度绩效报告自动生成

### 4. 数据管道增强 (Data Pipeline V2)
- 数据质量校验层：价格合理性、成交量异常、缺失值检测
- 增量同步状态机：断点续传、失败重试、同步进度追踪
- 多数据源容错：AkShare 失败时回退到备用源
- 数据血缘追踪：记录每条数据的来源和时间戳
- 历史数据版本管理

### 5. 执行引擎 (Execution Engine)
- 订单管理系统 (OMS)：订单生命周期追踪
- 细化滑点模型：基于成交量和波动率的动态滑点
- 成交模拟：部分成交、挂单超时
- 执行成本分析 (TCA)

### 6. 多组合管理 (Multi-Portfolio)
- 组合模板系统：保守型/均衡型/激进型预设
- 组合对比分析：收益、风险、持仓重叠度
- 组合快照与历史回溯
- 资金分配管理

### 7. 监控告警 (Monitoring & Alerting)
- 实时 P&L 监控
- 持仓集中度告警
- 数据新鲜度检查
- 策略健康度评分
- 异常检测（净值异常波动、成交量突变）

### 8. API 网关 (API Gateway)
- RESTful API 规范化（版本控制、分页、错误码）
- WebSocket 实时推送
- API 认证与限流
- OpenAPI 文档自动生成

## Capabilities

### New Capabilities
- `strategy-framework`: 策略注册表、因子库、策略组合器
- `risk-engine`: 仓位管理、相关性控制、VaR/CVaR、压力测试
- `analytics-dashboard`: 归因分析、基准对比、因子暴露、自动报告
- `data-pipeline-v2`: 数据质量校验、增量状态机、多源容错、数据血缘
- `execution-engine`: 订单管理、动态滑点、部分成交、TCA
- `multi-portfolio`: 组合模板、组合对比、资金分配
- `monitoring-alerting`: 实时监控、告警规则、健康度评分
- `api-gateway`: RESTful 规范、WebSocket、认证限流、OpenAPI

### Modified Capabilities
- `backtest-core`: 集成新策略框架和风控引擎
- `virtual-account`: 支持多组合、增强交易记录
- `cli-interface`: 新增 strategy/risk/portfolio/monitor 子命令
- `user-config`: 配置热更新、策略参数管理

## Impact

- **新增模块**：8 个核心模块，约 30+ 新文件
- **修改模块**：backtest/、config.py、cli.py、web/app.py
- **新增依赖**：scipy（优化求解）、statsmodels（统计检验）、plotly（可视化）、redis（可选，缓存）
- **测试增量**：每个模块配套单元测试 + 集成测试
- **预计工作量**：8 个 Phase，每 Phase 约 200-400 行代码 + 测试
